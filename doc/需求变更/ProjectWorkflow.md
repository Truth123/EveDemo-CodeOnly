# Project Workflow 需求变更

更新时间：2026-06-30

## 活跃规则

- 每轮启动不再默认全文读取 `doc/项目长期记忆.md` 和 `doc/需求变更记录.md`。
- 默认读取 `doc/当前上下文摘要.md`、`doc/索引/模块索引.md`、`doc/索引/任务关键词路由.md`。
- 根据任务关键词读取模块长期记忆、模块需求变更、需求文档、目录 README 和必要代码。
- 原大文件保留为完整历史追溯源，只在需要旧规则、历史原因或审计记录时按关键词定位读取。
- 阶段性交付后优先更新当前上下文摘要和相关模块长期记忆。
- 规则变更优先写入对应模块需求变更文件，并同步更新需求变更索引。
- 制定复杂计划前必须做语义审计：先确认玩法语义和不应触发的反例，再判断代码复用、合并、优先级或技术仲裁。
- 所有项目代码 `.cs` 文件必须维护中文文件头，说明文件职责、所属模块和运行影响。
- 所有项目代码函数、构造函数、Unity 回调、Editor 菜单函数和测试函数必须维护中文 XML `summary`，说明意图、副作用和跨模块影响。

## 近期变更入口

- 2026-06-23：启动摘要 + 索引 + 按需追溯文档体系重构。

## 遗留风险

- 当前项目代码范围已补齐文件头和函数注释；后续新增或修改代码时需要持续维护。
- 模块文档拆分后需要持续维护索引，否则后续仍可能回到全文搜索。
