# 战斗闭环调参与反馈计划

更新时间：2026-08-13
阶段：第 9 阶段 Boss 战可玩闭环校准与反馈基础

## 1. 阶段目标

第 9 阶段不优先继续新增大型战斗系统，而是把已经接入的玩家状态机、Boss AI、Motion Warp、HitNode、Guard / Evade / Reaction 放进真实 Boss 战闭环里校准。

本阶段目标是形成一段可用于求职演示的稳定 Boss 战小循环：

1. 玩家能完成移动、攻击、防御、防御移动、闪避、完美闪避、受击、击倒和死亡。
2. Boss 能按距离选择招式、接近、后撤、横移、环形闪移、命中、被玩家命中、被 Skill 击倒与被指定 HitNode PerfectGuard 反制。
3. Debug 面板能解释当前攻击距离、StopDistance、HitNode 语义拒绝、碰撞裁剪来源，以及玩家命中 Boss 后为何打断、击倒或未打断。
4. 命中、Guard、PerfectGuard、Knockdown 至少有可挂接的 HitStop、CameraShake、VFX、SFX 和 HUD 表现基础；PerfectEvade 使用 BulletTime / VFX / SFX / HUD 表现基础，不使用命中 HitStop。

## 2. 本阶段不做内容

1. 不新增大型 Boss P2。
2. 不做大范围剑气、QTE、处决演出或剧情系统。
3. 不重做玩家 / Boss 状态机架构。
4. 不引入大型事件框架或复杂 UI 框架。
5. 不让反馈层反向驱动伤害、资源、状态切换或输入窗口。

## 2.1 Demo 战斗数值基线

- 标准演示当前为玩家 `300 HP`、Boss `1500 HP / 15 护盾`；本轮主动降低 Boss 耐久以缩短战斗并提高演示容错。
- 玩家开局 `BE=0/32`，Skill1 消耗 8；资源必须通过普通命中、PerfectGuard 或 PerfectEvade 获取，正式场景不预填满能量。
- 玩家轻连段总伤害 54、重连段 50、Skill1 三段总伤害 200；Boss 单段伤害为 18～36，最高完整连段总伤害为 132。
- Boss 不使用阶段伤害倍率，Phase2 / Desperation 通过动作池和招式语义提高压力；`BossActionStrength` 是 AI 战术标签，不是伤害乘区。
- 普通防御、PerfectGuard 与 PerfectEvade 均为 0 HP 伤害；普通防御仍产生 GuardHit 反馈，黄光不可防、HitNode ReactionIntent 和 Guard/PG/PE authoring 不因数值调参改变。
- 双方 Timeline 伤害继续保持不变。旧 `2000 HP` 对应的 `1800/2200` 自动调节建议已失效；后续三次完整实机战斗只评估当前 `1500 HP / 15 护盾` 的体验，不同时修改生命和攻击伤害。

## 3. 当前反馈基础实现

本阶段新增轻量反馈分发链路：

```text
PlayerWeaponHitbox / BossAttackExecutor
→ CombatHitResult
→ CombatFeedbackEvent
→ CombatFeedbackBus
→ CombatFeedbackPlayer
→ HitStop / CameraShake / VFX / SFX
```

职责边界：

1. `CombatFeedbackEvent` 只描述表现请求。
2. `CombatFeedbackBus` 只做轻量分发，不保存战斗状态。
3. `CombatFeedbackEvent` 携带 `AttackType`，用于表现层区分 Light / Heavy / Skill 的 HitStop 和相机反馈调参。
4. `DamageOnly` 会发普通命中反馈，用于只扣 HP 的多段命中保留卡肉感；它不改变 Player / Boss 是否进入受击反应。
5. `CombatFeedbackPlayer` 可空引用运行；未绑定 VFX、SFX、HitStop 或 CameraRig 时跳过对应表现。
6. `CombatFeedbackPlayer` 通过 Inspector profile 按 `CombatFeedbackKind + CombatAttackType` 选择 HitStop 与 CameraShake 参数；CameraShake 不是所有命中默认触发。
7. `CombatHitStop` 使用 unscaled time 恢复 `Time.timeScale`，避免 HitStop 持续时间受自身缩放影响。
8. `PlayerCameraRig.AddShake(...)` 只叠加最终相机位置偏移，不改变锁定目标、碰撞修正或相机朝向规则。
9. 正式演示 HUD 使用运行时创建的 `DemoBattleUICanvas`，显示 Boss HP / 护盾、玩家 HP / BE 与右下两列三行静态操作卡片；卡片标题为“H 键隐藏”，Combat 中可用 H 单独隐藏或恢复。左上训练快捷提示已删除，右上 Boss AI 调试信息默认隐藏。
10. 旧 `CombatHudOverlay` 作为 OnGUI fallback 保留，但 Demo UI 启动时默认关闭，避免资源条重复显示。
11. `DemoBattleUiController` 只保留展示层 `ESC` 暂停与 H 操作说明显隐快捷键；右上 Boss AI 调试信息默认隐藏，仅由场景 `showDebugOnStart` 开发配置开启。两项快捷键均不写入 `PlayerInputSnapshot`，不影响玩家状态机输入语义。
12. 暂停菜单进入前会取消当前 `CombatHitStop`，避免 HitStop 恢复时覆盖 `Time.timeScale = 0`。
13. 攻击出手过程 VFX 不经过 `CombatFeedbackBus`；Player 武器拖尾当前只保留手动配置的 `SlashTrailVFX` / 场景资产，Boss 持续拖尾按 HitNode SourcePart 固定路由，直刺表现继续由 Boss 根对象人工绑定，命中接触仍走上面的反馈链路。

### 3.0.1 Combat Feedback V1 调参基线

V1 暂不做 Target Material Flash，也不新增正式视觉特效方案；优先用 HitStop 形成卡肉感，再按 profile 选择少量相机反馈。

| 类型 | 默认表现 |
| --- | --- |
| Light 普通命中 | 短 HitStop，默认不 CameraShake |
| Heavy 普通命中 | 更明显 HitStop，可轻微 CameraShake |
| Skill DamageOnly | 短 HitStop，默认不 CameraShake |
| Skill Knockdown / Dead | 更强 HitStop，并 CameraShake |
| GuardHit | 短促 HitStop 与相机反馈 |
| PerfectGuard | 接触防御反馈：HitStop 0.06s / TimeScale 0.06，CameraShake 0.075 / 0.12s / 34Hz，白金接触爆发与 `Assets/Audio/hit_perfect.mp3` |
| PerfectEvade | 短子弹时间和红色方向线，不使用命中 HitStop，默认不 CameraShake |

### 3.0.2 剑类攻击 VFX V1

当前出手表现以可人工调节的场景 / Prefab 资源为准。Boss 拖尾在绑定 HitNode 整个激活窗口采样；直刺在首帧生成世界空间实例，之后不跟随骨骼。同一 HitNode 可同时配置两类效果，未绑定节点不播放，且所有出手 VFX 均不参与命中结算。

| 类型 | 默认表现 |
| --- | --- |
| Eve Light | 较细短的蓝白剑刃拖尾 |
| Eve Heavy | 更宽更亮的青蓝拖尾和短弧光 |
| Eve Skill1 | 全段青蓝拖尾，第三段 Knockdown HitNode 触发更强蓝白挥砍弧光 |
| Raven 普通 Slash | 短红色危险拖尾和弧光 |
| Raven Rush / Chase / 多段压迫 | 更长红 / 紫红残线和更宽弧光 |
| PerfectEvade | 子弹时间期间生成短红色方向线，不触发命中火花或 PerfectGuard 火花 |

## 4. Play Mode 回归矩阵

### 4.0 演示 UI 与暂停

| 验证项 | 期望结果 |
| --- | --- |
| 进入战斗 | 显示 UGUI 战斗 HUD，右下默认显示标题为“H 键隐藏”的六项静态战斗操作，旧 `SkillWheel` 与 OnGUI `CombatHudOverlay` 不重复显示；右上 Boss AI 调试信息默认隐藏 |

| 验证项 | 期望结果 | 观察字段 |
| --- | --- | --- |
| Light / Heavy 命中 Boss Idle / Approach / Strafe / Recovery | Boss 播放站立受击并回到 Idle 评估 | `Received Player Hit / Interrupted / Direction` |

| 未标记的 HitNode 被 PerfectGuard | Boss 不进入 JustParry，继续当前攻击流程 | `LastOutcome=PerfectGuard` |
| Boss HP 归零 | 进入 Dead，不被 HitStagger 或 Knockdown 覆盖 | `BossState=Dead` |

## 6. 已知风险

1. HitStop 使用 `Time.timeScale`，虽然持续时间很短，但仍可能影响依赖 `Time.deltaTime` 的状态计时；如果后续出现输入窗口体感异常，需要考虑改成动画 / 输入层局部暂停方案。
2. VFX / SFX 当前绑定的是开发期占位资源，能用于区分反馈类型，但不是最终美术和混音。
3. HUD 当前是 OnGUI 轻量演示版，不是最终 UI 架构。
4. Boss Motion Warp 和 HitNode 数值仍必须逐招 Play Mode 校准，静态检查无法替代手感验证。
