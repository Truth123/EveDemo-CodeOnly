# Camera Runtime

本目录承载战斗相机运行时代码，负责自由视角、锁定视角、关注点平滑、快速位移跟随缓冲和 CameraShake 最终叠加。

## 职责

- 根据玩家、锁定目标和输入驱动相机位置与朝向。
- 在 Evade / PerfectEvade / Skill 等快速位移后平滑追赶关注点。
- 管理锁定视角下的目标跟随和战斗构图。
- 为 Demo 开场提供锁定战斗位姿计算与外部镜头交接缓存同步；标题锚点和过渡协程仍由 UI 展示层管理。
- 接收反馈系统的 CameraShake，并只叠加最终相机位置。

## 边界

- 不改变玩家或 Boss 的实际位移。
- 不改变锁定目标选择规则以外的战斗状态。
- 不在相机层处理命中结算或输入缓存。
- 不从标题镜头阶段自行启动玩家锁定或 Boss AI。
